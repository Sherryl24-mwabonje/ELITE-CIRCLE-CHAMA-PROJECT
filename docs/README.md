# ELITE CIRCLE CHAMA MANAGEMENT SYSTEM

## 1. Project Description

The Elite Circle Chama Management System is a Java-based desktop application developed to help manage chama activities. It provides a simple interface for managing members and recording their financial contributions.

The application uses Java Swing for its graphical user interface and MySQL for database management.

## 2. Project Objectives

- Simplify the management of chama members.
- Record and manage member contributions.
- Store information in a structured database.
- Reduce manual record-keeping.
- Improve accuracy and accessibility of chama records.

## 3. Technologies Used

- **Programming Language:** Java
- **GUI Framework:** Java Swing
- **Database:** MySQL
- **Database Connectivity:** JDBC
- **IDE:** Visual Studio Code
- **Version Control:** Git and GitHub

## 4. Main Features

### Member Management
- Add new members.
- View registered members.
- Update member information.
- Delete member records.

### Contribution Management
- Record member contributions.
- View contribution records.
- Update contribution details.
- Delete contribution records.

## 6. Database

The application uses MySQL to store member and contribution information.

The database includes relationships between members and their contributions using primary keys and foreign keys.

## 7. How to Run the Application

1. Install Java Development Kit (JDK).
2. Install and configure MySQL.
3. Import the project database schema.
4. Configure the database connection properties.
5. Add the MySQL Connector/J library.
6. Open the project in Visual Studio Code.
7. Run the application through the main Java class.
